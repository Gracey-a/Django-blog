A full‑featured, production‑ready blog platform with authentication, rich text editing, post scheduling, comments, likes, dark/light mode, and persistent image hosting.

**🔗 [Live Demo](https://django-blog-52oj.onrender.com)** · **📁 [GitHub Repo](https://github.com/Gracey-a/Django-blog)**

---

## ✨ Features

- **User authentication** – registration, login, profile (JWT + sessions)
- **Rich text editor** – CKEditor integration
- **Post scheduling** – write drafts, publish later
- **Comments & likes** – engage readers
- **Categories & tags** – organise content
- **Dark / light mode toggle** – magazine‑style layout
- **Persistent image hosting** – Cloudinary integration
- **Responsive design** – works on all devices

---

## 🛠️ Tech Stack

- **Backend:** Django, Django REST Framework (DRF)
- **Database:** PostgreSQL (production), SQLite (development)
- **Frontend:** Tailwind CSS, JavaScript
- **Image hosting:** Cloudinary
- **Deployment:** Render.com (with Gunicorn and Whitenoise)
